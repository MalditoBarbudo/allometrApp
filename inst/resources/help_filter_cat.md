### Selecció d'alometries

Les alometries disponibles es poden filtrar les diferents característiques:   

- Per variable dependent   
- Per variable o variables independents   
- Per nivell de l'alometria (planta o orgue)   
- Per nivell espacial de l'alometria (nacional, comunitat, província, comarca)   
- Per nivell del grup funcional (gènere, grup d'espècies, espècie)   
- Per grup funcional específic (espècie o gènere concret)   
- Per forma de cubicació (definit als inventaris)   
- Per *Quercus suber*, pel valor del paràmetre especial (definit als inventaris)

### Descàrrega de la taula d'alometries

La taula d'alometries, sencera o aquelles que s'han seleccionat, es poden descarregar fent clic al botó corresponent al format desitjat (`csv` o `xlsx`).

### Càlcul d'alometries

La pestanya de càlcul permet seleccionar un fitxer amb dades (`csv` o `xlsx`) i les alometries a calcular, així com mapejar les variables del fitxer amb les variables de les alometries. El càlcul es produeix al vol quan tot està seleccionat i el resultat es pot descarregar fent clic al botó corresponent.
